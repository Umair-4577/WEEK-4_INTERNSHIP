# Week 4 - Enhancing Web Page Performance and Accessibility

## Files
- `index.html` - semantic and accessible webpage
- `styles.css` - optimized responsive CSS
- `Week_4_Performance_Accessibility_Report.pdf` - submission report

## How to run
Open `index.html` in a browser.

## Suggested testing
Run Lighthouse in Chrome DevTools and test the page with WAVE and axe DevTools. Also test all links and form controls using only the keyboard.
